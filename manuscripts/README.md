# Sanskrit palm-leaf manuscript images

Use these JPEG files in the manuscript reader. Each file shows a leaf, a group of leaves, or a detail. The source records identify the language as Sanskrit. The script varies by manuscript.

For the first demo, open **Translate** and select **Sanskrit**. Upload [the Āpastamba Mantrapāṭha image](apastamba-mantrapatha.jpg). It shows a narrow Grantha leaf from the Whish collection. Use the Vedic manuscript image to test reading order across several leaves.
